# Security policy

This plugin is part of ibara, and ibara's security policy covers it.

Report a vulnerability privately through GitHub, on the Security tab of [MayberryDT/ibara](https://github.com/MayberryDT/ibara/security): choose Report a vulnerability. Please do not open a public issue about it.

ibara's [security policy](https://github.com/MayberryDT/ibara/blob/main/SECURITY.md) says what to include and which versions get fixes. We will reply to your report within 7 days. Only the newest release is supported, and `ibara update` updates this plugin with it.
